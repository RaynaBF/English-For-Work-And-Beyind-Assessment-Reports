# English for Work. And Beyond. English Assessment reports

Static copy of the candidate English Assessment report site (CEFR-based profile with 13 dimensions,
professional communication, further evidence and notes, in English and Portuguese), published with GitHub Pages.

Each report opens with a personal link that ends in its own code (`...#code`).
The report data is stored encrypted in `data/`. The page decrypts it in the browser with the code
from the link, so the files cannot be read without it.

Do not edit `index.html` or `data/` by hand. They are generated by `tools/build_assessment.py`
(see the docstring at the top of that file). The link codes are not stored in this repository.
